# 04-areas

Ongoing responsibilities without an end date, for example career, family,
finances, health, learning. Listed in
[the area index](../00-system/indexes/areas.md).

**Areas are created from real usage, not upfront.** When triage keeps
routing captures to the same life domain, that domain has earned an area
file (template: [area.md](../00-system/templates/area.md)). Do not
pre-create every conceivable category: empty categories cost attention and
return nothing.

One file per area until it actually grows; then a folder, same as projects.
Projects belonging to an area live in `03-projects/` and are linked from the
area file.
