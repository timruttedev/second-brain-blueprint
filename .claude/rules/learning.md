# Rule: Learning Layer

Writing into `00-system/learning/`. The loop itself is in
[AGENTS.md](../../AGENTS.md#learning) and the
[learning loop](../../00-system/workflows/learning-loop.md).

- **Signposts stay small.** `observations.md` and `organization-log.md`
  hold the format and the month table only. Write entries into the current
  month's file (`observations/YYYY-MM.md`, `organization-log/YYYY-MM.md`);
  create it and add a table row if it is missing.
- **Observations are one line each:** friction, repeated searches,
  repeated owner corrections.
- **Promote with evidence only.** An observation becomes a pattern after
  about three occurrences or explicit owner confirmation.
- **Prefer the smallest reversible improvement.** Park bigger ideas in the
  optimization backlog.
- **Every organization-log entry names its evaluation.** While open:
  `_open, review on YYYY-MM-DD: <what to check>._` After evaluating, fill
  `Result:` with keep, modify or revert. A revert is the system learning,
  not a failure.
