# Principles

The standing principles of this Second Brain. They change rarely and only
deliberately. Everything else in the system serves them.

1. **Preserve knowledge, evolve structure.** Information, facts, decisions
   and history are permanent. Folders, names, taxonomies, templates and
   workflows are implementation details that may change when it helps.
2. **Capture first, organize later.** Getting information in must cost
   nothing. Filing is the system's job, done at triage time.
3. **Search before create.** Always check for an existing canonical home
   before writing a new file.
4. **Canonicalize instead of duplicate.** One canonical location per fact.
   Everything else links to it.
5. **Preserve history.** Information must not disappear because the
   structure changed, or because it stopped being current. Archive before
   delete.
6. **Explicit decisions beat inferred assumptions.** What the owner stated
   outranks what an AI inferred. Assumptions are labeled as such.
7. **The latest explicit statement defines current state.** Previous state
   remains as history, visibly dated.
8. **Structure may evolve.** The system is allowed and expected to improve
   its own organization, with a reason, logged when significant.
9. **Optimize for retrieval, not aesthetics.** A structure is good when the
   right information is found fast, not when the tree looks elegant.
10. **Humans and AI must both understand the repository.** Plain Markdown,
    readable names, human-readable indexes, no proprietary formats.
11. **Small contexts win.** Agents load narrowly (context, then index, then
    canonical file), never the whole repository.
12. **No secrets, ever.** Passwords, API keys, recovery codes and the like
    are never stored here. Only references to where they live.
13. **Structure follows complexity.** Small things stay one file.
    Substructure is created when something actually grows, not in advance.
14. **Capture raw, store distilled.** The inbox takes everything. The
    canonical base keeps only condensed, future-useful knowledge. This is
    not a chat archive.
15. **Evidence before rules.** Observations become patterns, patterns
    become structure. Not every one-off idea changes the architecture.
16. **A rule nothing checks does not hold.** When a rule keeps breaking,
    make a script or a grep check it, instead of rewording it.
