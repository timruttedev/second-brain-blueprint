# Workflow: Create Project

Purpose: turn a time-bounded effort with a definable outcome into one
findable project file.

1. **Check that it really is a project.** Has an end state → project.
   Ongoing responsibility → area. One-off task → open loop in the owning
   area or project.
2. **Search first**: does a project (active or archived) for this already
   exist? Reactivate or extend it before creating a new one.
3. **Create one file** `03-projects/<name>.md` from
   [the project template](../templates/project.md): what, why, goal,
   current state, next steps. No folder, no five files.
4. **Register it**: add it to [the projects index](../indexes/projects.md);
   link it from the owning area file (if there is one); add it to
   [`current-context.md`](../current-context.md) if it is a current focus.
5. **Link founding decisions** in `07-decisions/` if a durable choice was
   made (see [decision-record.md](./decision-record.md)).

Growth path: when the single file gets unwieldy, convert it to
`03-projects/<name>/README.md` and split out only what actually grew. Update
all links (see [reorganization.md](./reorganization.md)).
Completion path: see [archive.md](./archive.md).
