# 03-projects

Time-bounded efforts with an outcome ("done" is definable). Listed in
[the project index](../00-system/indexes/projects.md) while active.

- Template: [project.md](../00-system/templates/project.md). Small project =
  **one file** (`project-name.md`). A growing project becomes a folder
  (`project-name/README.md` plus what actually grew). Structure follows
  complexity, never five files by default.
- A recurring theme without an end date is an **area** (`04-areas/`), not a
  project.
- Finished or dead projects move to `09-archive/projects/` (status noted)
  and leave the index. Their decisions stay in `07-decisions/`.
- Workflow: [create-project](../00-system/workflows/create-project.md).
