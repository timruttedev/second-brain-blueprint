# 09-archive

Inactive content, preserved. **Archive before delete:** this is where things
go instead of being removed.

- Mirror the source location (`09-archive/projects/<name>.md`,
  `09-archive/areas/...`), so the origin stays obvious.
- On archiving: set `status: archived` (with a one-line reason and date at
  the top), remove the entry from its index, and fix links that pointed to
  the live location.
- Archived content is left out of default retrieval; search it only for
  explicitly historical questions.
- Un-archiving is always allowed: move it back and re-index.
- Workflow: [archive](../00-system/workflows/archive.md).
