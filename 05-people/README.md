# 05-people

Person records: one file per person (`firstname-lastname.md`, template:
[person.md](../00-system/templates/person.md)). Currently relevant people
are listed in [the people index](../00-system/indexes/people.md).

**People in the closest circle (family and comparably close people) get a
file at first mention**, even if only three facts are known. The file is the
anchor that content grows on; do not wait for "enough" material and do not
park their data in an area file instead.

For everyone else, create a file when it is useful long-term: the person
relates to the owner's life, projects, or open loops. **No profile
collecting for its own sake.** Someone mentioned once in a journal entry
does not need a file.
