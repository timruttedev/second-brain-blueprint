# 05-people

Person records: one file per person (`firstname-lastname.md`, template:
[person.md](../00-system/templates/person.md)). Currently relevant people
are listed in [the people index](../00-system/indexes/people.md).

Create a file when it is useful long-term: the person relates to the
owner's life, projects, or open loops, and facts about them keep coming
up. Once a person has a file, their facts go there, not into an area or
project file; link to the person instead. Whether close people (family,
partner) get a file right away or only once there is material is the
owner's choice; record it in `00-system/learning/patterns.md` once it is
clear. **No profile
collecting for its own sake.** Someone mentioned once in a journal entry
does not need a file.
