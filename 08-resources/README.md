# 08-resources

External reference material: links, documents, excerpts, manuals, articles.
Things the owner did not author but wants to keep or find again.

- Prefer a link plus a few lines of "why kept, key takeaway" over pasting
  whole documents.
- Insight from a resource that becomes the owner's working knowledge belongs
  in `06-knowledge/`, linking back here.

## Attachments

The repository is a knowledge base, not a file dump (see
[AGENTS.md](../AGENTS.md)):

- **Small, relevant assets** (images, PDFs): allowed, here or next to their
  owning content, clearly named, referenced from the note that needs them.
- **Large files** (videos, big archives, anything that would bloat Git):
  keep them in external storage and store only a reference here: location,
  one-line description, date. Decide on a storage convention when the need
  actually arises.
- **Never** identity documents or files containing secrets.
