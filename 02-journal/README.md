# 02-journal

Time-based notes and reviews. Templates in
[00-system/templates](../00-system/templates/README.md), process in
[reviews](../00-system/workflows/reviews.md).

| Dir | File name | Purpose |
|---|---|---|
| `daily/` | `YYYY-MM-DD.md` | Capture and events; cheap, optional |
| `weekly/` | `YYYY-Www.md` (for example `2000-W01.md`) | Condense the week; triage; update indexes and context |
| `monthly/` | `YYYY-MM.md` | Larger patterns; system health pass |
| `yearly/` | `YYYY.md` | Long-term development; system retrospective |

Journal files are history: they are not updated retroactively. Corrections
happen in the canonical files.
